# 安全规则（Sigwalk）

## 签名结论

- 文件状态只能由 `WinVerifyTrust` 的逐签名结果决定；**不得**用“能否取到证书”判断签名有效。
- 不得忽略证书链错误；系统信任策略即权威策略。
- `Unsigned` 与 `Invalid` 必须区分：
  - 无签名码 + `CryptQueryObject` 无嵌入签名 → Unsigned；
  - 有嵌入签名但验证失败 → Invalid；
  - 验证异常/无法归类 → Unknown。
- 不得默认启用 `WTD_LIFETIME_SIGNING_FLAG`（会改变带时间戳签名的有效期语义）。
- 始终设置 `WTD_DISABLE_MD2_MD4`，拒绝弱哈希算法。
- 不使用官方标注“不支持”的 `WTD_SAFER_FLAG`。
- 目录签名（Catalog）当前不支持；文档与界面必须明确说明，不得暗示可检测。

## 网络

- 默认离线：不联网检查吊销。
- 只有用户显式选择“缓存/在线吊销”时才允许网络访问。
- 在线模式下应限制并发并提示可能变慢。
- 不得在签名验证之外主动上传文件信息、路径或证书。

## 文件访问

- 扫描文件只读打开：`FileAccess.Read` + `FileShare.ReadWrite | Delete`，不得修改被扫描文件。
- 不执行、不加载、不反射被扫描程序集。
- 哈希流式读取，禁止一次性读入内存。
- 扫描前后校验大小/修改时间；不得把变化中的文件结果当作完整结果。
- 路径过长、无权限、占用、文件不存在等错误必须归为扫描失败并记录，不得崩溃。

## P/Invoke

- 结构体尺寸/偏移必须由测试固定。
- 所有原生句柄判空；state data 必须在 `finally` CLOSE。
- 只在 state 有效期内复制证书/字符串/时间；禁止跨 CLOSE 使用原生指针。
- 对 `WTHelper*` 返回值做防御性检查，避免 `PtrToStructure` 空指针。

## 输出与界面

- CSV/XLSX 导出必须正确转义引号、换行和 XML 非法字符；防止公式注入由用户自行评估（当前导出为文本）。
- 日志中不记录证书私钥（本工具不涉及私钥）或敏感凭据；文件路径与错误信息可记录。
- 全局异常必须写日志并提示，不得静默退出。
- 应用以 `asInvoker` 运行，不请求管理员权限。
- 打开文件/目录/资源管理器定位使用 `UseShellExecute`；不得拼接到 shell 命令中。
